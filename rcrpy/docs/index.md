# rcrpy

Robust Chauvenet Rejection (RCR) — advanced, but easy-to-use, statistical
outlier rejection that stays accurate even on samples that are more than 85%
contaminated. `rcrpy` is the pure-Python reimplementation of the RCR algorithm
from [Maples et al. 2018](https://arxiv.org/abs/1807.05276).

## Installation

```bash
pip install rcrpy
```
